lilita-one-latin.woff2 is the Latin subset as served by Google Fonts, copied unchanged.

nunito-latin.woff2 is a subset of the upstream variable font Nunito[wght].ttf, version 3.602 (github.com/google/fonts,
ofl/nunito; SHA-256 bb55a5ca5c2042335b3991af27c4d0705d0ef41cac6164ac737fd8f2a1e85207): the code points and layout
features of the Google Fonts Latin subset, plus U+2248 "≈" (the overlay page's "less certain" mark). Every other glyph has the
same outline and advance width as the Google Fonts file. Made with fonttools 4.68.0:

pyftsubset "Nunito[wght].ttf" --flavor=woff2 --output-file=nunito-latin.woff2 --no-glyph-names --notdef-outline
  --hinting --name-IDs='*' --name-languages='*' --layout-features="calt,ccmp,dnom,frac,kern,liga,locl,mark,mkmk,numr"
  --unicodes="U+0000,U+000D,U+0020-007E,U+00A0-00FF,U+0102,U+0131,U+0152-0153,U+02BB-02BC,U+02C6,U+02DA,U+02DC,
  U+0300-0301,U+0303-0304,U+0308-0309,U+0323,U+2009,U+200B,U+2013-2014,U+2018-201A,U+201C-201E,U+2022,U+2026,
  U+2032-2033,U+2039-203A,U+2044,U+20AC,U+2122,U+2212,U+2215,U+2248"
(one command line; the --unicodes list has no spaces)
